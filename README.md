# A.N.G.E.L.S. Prototype

Clickable dashboard prototype for the Army Network Global Equipment Logistics System.

## Netlify

This is a static prototype. Netlify can publish the repository root with no build command.

## Files

- `index.html` - prototype screens
- `styles.css` - dashboard styling
- `app.js` - clickable prototype interactions
- `assets/angels-logo-banner.png` - A.N.G.E.L.S. banner
